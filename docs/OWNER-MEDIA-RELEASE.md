# รุ่น UI และระบบเจ้าของ — 24 ตุลาคม 2569

ยังไม่เผยแพร่ main และยังไม่เปลี่ยนฐานข้อมูลหรือรายชื่อเจ้าของ

## สิ่งที่พร้อมตรวจ

- UI พาสเทล เมนูเดิม พี่ชาร์คกี้ โหมดมือถือ/คอม และการแจ้งจุดเสี่ยง
- อ่านสื่อและการ์ตูนจากตารางเดิม 8 รายการ
- จัดการสื่อหลายหน้า แก้ชื่อ เรียงลำดับ ถังพัก และกู้คืน เฉพาะเจ้าของ
- client ส่ง ownerToken ตรงกับ Apps Script รุ่นที่ตรวจใน dashboard แล้ว
- ใช้บัญชีเดิมผ่านอีเมล/รหัสผ่าน เพราะอีเมลระบบเดิมส่งลิงก์ ไม่ใช่ OTP
- ไม่สร้างบัญชี ไม่เปลี่ยนรหัสผ่าน ไม่เก็บ session ถาวร ตรวจ getUser และ owner RPC ก่อนใช้งาน
- ตัวอย่างอ่านข้อมูลจริงและทดสอบล็อกอินได้ แต่ยังปิดการบันทึกจริง

## ผลทดสอบ

Local tests ผ่าน 7 ชุด: กฎไฟล์/ลำดับ/URL, token ผิดหรือหมดอายุ, anonymous/non-owner, ปิดก่อนแตะชีท, ป้องกันเหตุซ้ำ, formula escaping และ transport แจ้งจุดเสี่ยง

SQL ทดสอบ RLS สำหรับผู้ใช้ทั่วไปและ non-owner ผ่าน โดยข้อมูลทดสอบ rollback แล้ว
Browser QA อ่านการ์ตูนเดิมและไปหน้าถัดไปได้

## ยังต้องตรวจ

- บัญชีเจ้าของยืนยันอีเมลแล้ว ยังต้องทดสอบเข้าสู่ระบบในหน้าเว็บใหม่
- แก้ลิงก์กลับหลังยืนยันอีเมลเป็นเว็บจริงแล้ว
- เพิ่มสื่อหลายหน้า จัดลำดับ ถังพัก กู้คืน และเพิ่มอุบัติเหตุครบวงจร
- Merge/deploy หลังผ่านการตรวจ และทดสอบ cache รุ่นเดิม

## ถังพักและย้อนกลับ

รายการถังพักซ่อนจากคลัง แต่ URL รูปที่เคยแชร์ยังเปิดได้ตาม public bucket เดิม ไม่ลบไฟล์จริงเพื่อให้กู้คืนได้

ย้อน UI โดย revert commit และเปลี่ยน cache version ไม่ต้องลบตารางหรือภาพ เก็บรุ่น Apps Script เดิมก่อนแก้ ห้ามย้อน backend gate ให้เปิดการเพิ่มอุบัติเหตุสาธารณะ
