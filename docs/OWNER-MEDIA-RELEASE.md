# รุ่น UI และระบบเจ้าของ — ตรวจระบบจริง 24 ตุลาคม 2569

## ผ่านการตรวจ

- เข้าสู่ระบบบัญชีเจ้าของจริงบนหน้าทดสอบออนไลน์ ตรวจ getUser และ owner RPC สำเร็จ
- อัปโหลดภาพจริงสองหน้า สลับลำดับหน้าก่อนบันทึก และเปิดตัวอ่านหน้า 1/2 กับ 2/2 ได้ ภาพโหลดสำเร็จ
- เพิ่มรายการที่สอง เลื่อนขึ้นก่อนรายการแรก และตรวจผลลำดับจาก UI
- แก้ชื่อรายการ ย้ายเข้าถังพัก กู้คืน และตรวจข้อความสำเร็จจากระบบจริง
- เรียกอ่าน API แบบผู้ใช้ทั่วไปแล้วไม่เห็นรายการในถังพัก
- เก็บรายการทดสอบทั้งสองในถังพักเมื่อจบ ไม่ลบสื่อเดิม
- เรียก API เพิ่มอุบัติเหตุจริงด้วย token ที่ไม่ถูกต้องแล้วถูกปฏิเสธก่อนบันทึก
- Apps Script deployment เดิมมี owner gate ก่อนแตะข้อมูล และ client ใช้ ownerToken ตรงกัน
- ไม่เพิ่มอุบัติเหตุสมมติลงฐานข้อมูลจริง การทดสอบสิทธิ์เจ้าของที่เขียนอุบัติเหตุใช้ unit harness
- Local tests ผ่าน 7 ชุด ครอบคลุมไฟล์/ลำดับ/URL, token, non-owner, ปิดก่อนแตะชีท, ป้องกันเหตุซ้ำ, formula escaping และ report transport
- SQL RLS สำหรับผู้ใช้ทั่วไปและ non-owner ผ่านโดย rollback fixture

## การใช้งาน

เว็บหลักมีเมนูเข้าสู่ระบบเจ้าของ ใช้อีเมลและรหัสผ่านบัญชีเว็บไซต์ที่ยืนยันแล้ว เพิ่มรูปหลายหน้า แก้ชื่อ เรียงรายการ ย้ายถังพัก และกู้คืนได้

หน้าตั้งรหัสใหม่: account/reset.html เชื่อม redirect ของระบบ Auth แล้ว ผู้ใช้ต้องตั้งรหัสเอง

## ข้อมูลและสิทธิ์

ใช้ตาราง ภาพ และรายชื่อเจ้าของเดิม ไม่มีการย้ายฐานข้อมูลหรือเพิ่มสิทธิ์ผู้ใช้อื่น ไม่เก็บ session ถาวร

รายการถังพักถูกซ่อนจากคลัง แต่ URL รูปที่แชร์ไว้ยังเปิดได้ตาม public bucket เดิม ไม่ลบไฟล์จริงเพื่อให้กู้คืนได้

## ย้อนกลับ

ย้อน UI โดย revert commit ที่เผยแพร่และเปลี่ยน service worker cache version ไม่ต้องลบตารางหรือภาพ เก็บ Apps Script รุ่นเดิมไว้ ห้ามย้อน owner gate ให้เปิดเพิ่มอุบัติเหตุสาธารณะ
