# สถิติกรมทางหลวงจากข้อมูลทางการ TRAMS

หน้าหลักและหน้าเมนู “สถิติอุบัติเหตุ” ใช้ `data/trams-doh.json` ชุดเดียวกัน ผ่าน `site/official-stats.js` ไม่ใช้แท็บสถิติใน Google Sheet อีกต่อไป ระบบจุดเสี่ยงและอุบัติเหตุไรเดอร์ยังใช้แหล่งเดิม

## การแสดงผล

- ครบ 77 จังหวัด รวมกรุงเทพมหานคร กรองเฉพาะหน่วยงานกรมทางหลวง ไม่ใช่ทุกถนนและไม่ใช่เฉพาะไรเดอร์
- บัตรหน้าแรกเป็นยอดทั่วประเทศเสมอ ตัวกรองจังหวัดเปลี่ยนเฉพาะบัตร ตาราง และสาเหตุในหน้าสถิติ
- สัดส่วน จยย. = ระเบียนที่มี จยย. อย่างน้อย 1 คัน / ระเบียนเหตุ ไม่ใช้ค่าเฉลี่ยร้อยละข้ามจังหวัด
- มูลเหตุสันนิษฐานรวมจากฟิลด์ต้นทางจริง แทนกราฟร้อยละที่เคยใส่ไว้คงที่
- แยกวันเหตุการณ์ล่าสุด วันปรับปรุงไฟล์ต้นทาง และเวลาตรวจ/นำเข้าสำเร็จ ข้อมูลต้นทางอาจเก่ากว่าวันตรวจ
- โหลดอัตโนมัติเมื่อเปิดเว็บและทุก 15 นาทีที่เปิดหน้าจออยู่ ปุ่ม “โหลดผลล่าสุด” อ่านไฟล์ผลนำเข้าล่าสุด ไม่มีการดึง CSV ขนาดใหญ่บนมือถือ
- หากโหลดใหม่ไม่ได้ จะคงผลเดิมในหน้าที่เปิดอยู่และแจ้งข้อผิดพลาด ครั้งแรกที่ไม่มีข้อมูลจะแสดงขีดแทนการอ้างว่าไม่มีเหตุ
- จังหวัดที่ไม่มีระเบียนแสดงขีดและสถานะ ไม่อนุมานว่าจังหวัดนั้นไม่มีอุบัติเหตุ ระเบียนกรมทางหลวงที่ระบุจังหวัดไม่ได้ถูกแยกกลุ่มแต่ยังรวมในยอดประเทศ

## การตรวจต้นทางตามเวลา

ตั้งงานอัตโนมัติใน ChatGPT ให้ตรวจและนำเข้าทุกเช้า (เวลาไทย) งานใช้ตัวนำเข้าที่เก็บใน repository นี้และอัปเดตเฉพาะ `data/trams-doh.json` ผ่าน GitHub App จึงเกิด GitHub Pages build ตามปกติ ไม่มีการเปิดเผยรหัสผ่านหรือใช้ token ฝังในเว็บ

การอัปเดตตัวเลขขึ้นกับการเผยแพร่ของกระทรวงคมนาคม ไม่ใช่รายงานสด หากงานอัตโนมัติถูกหยุดหรือบัญชี GitHub หลุดการเชื่อมต่อ ต้องแก้ที่งานอัตโนมัติ/การเชื่อมต่อ หน้าเว็บยังระบุเวลานำเข้าสำเร็จครั้งก่อนตามจริง

## นำเข้าและทดสอบ

```sh
python scripts/sync_trams.py
python -m unittest discover -s tests -p test_trams.py -v
node --test tests/official-stats.test.cjs tests/owner-access.test.cjs
```

ไม่ระบุปีจะเลือก CSV ปีล่าสุดที่เผยแพร่และไม่เกินปีปัจจุบันตามเวลาไทย (รองรับต้นปีที่ยังไม่มีไฟล์ปีใหม่) ระบุ `--year 2026` เพื่อบังคับปีได้ แหล่ง catalog: https://datagov.mot.go.th/api/3/action/package_show?id=roadaccident

ใช้ Python 3 มาตรฐาน ไม่ติดตั้งแพ็กเกจ ตรวจ schema/ปี/วันที่/ตัวเลข/ผลรวมก่อนเขียนแบบ atomic จึงเก็บผลสำเร็จครั้งก่อนเมื่อดาวน์โหลดหรือข้อมูลผิดพลาด ตรวจซ้ำจากไฟล์ทางการที่ดาวน์โหลดไว้ด้วย `--catalog /path/catalog.json --csv /path/accident2026.csv` ได้ ข้อมูลดิบไม่ถูก commit เผยแพร่เฉพาะยอดสรุป

CSV ใช้วัน/เดือน/ค.ศ. `resourceModifiedAt` เก็บตามต้นฉบับโดยไม่สมมติ timezone และแสดงเฉพาะวันที่ ส่วน `fetchedAt` เป็น UTC พร้อม timezone และแสดงเวลาไทย

ผลเริ่มต้นปี 2569: เหตุ 1 ม.ค.–12 ต.ค. 2569, กรมทางหลวง 16,318 ระเบียน เสียชีวิต 1,836 คน บาดเจ็บสาหัส 1,943 คน บาดเจ็บรวม 13,477 คน พบครบ 77 จังหวัด แถวเหมือนกันทุกช่องในชุดกรมทางหลวง 0 แถว (ทั้งไฟล์ทุกหน่วยงานมี 21 แถว) ข้ามแถวว่าง 3,979 แถว
