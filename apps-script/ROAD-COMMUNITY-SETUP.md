# ฟอร์มอุบัติเหตุและแชทจุดเสี่ยง

เพิ่มไฟล์ RoadCommunity.gs ใน Apps Script เดิม ไม่แทนที่ doGet/doPost เดิม

## เชื่อมเส้นทาง

1. ใน doGet(e) ก่อนเส้นทางทั่วไป ถ้า e.parameter.sheet === 'road_chat' ให้คืน roadCommunityJson_(readRoadChat_(e.parameter.room))
2. ใน doPost(e) หลัง JSON.parse(e.postData.contents) และก่อนเส้นทางเดิม เรียก handleRoadCommunity_(payload) ถ้าผลไม่ใช่ null ให้คืน roadCommunityJson_(ผล)
3. ถ้า apiPostReport ไม่ได้ส่งต่อ doPost ให้เชื่อม handler เดียวกันและคืน JSON.stringify(ผล)
4. apiGetData ของเว็บ Apps Script ต้องรองรับ sheet=road_chat&room=... เหมือน doGet
5. อัปเดต deployment เดิมหลังตรวจเส้นทางเดิมยังทำงาน

## ข้อมูลและการตรวจสอบ

ฟอร์มบันทึกเฉพาะคอลัมน์เดิมในแท็บ อุบัติเหตุจริง สร้างรหัส INC-UUID และสถานะ รอตรวจสอบ ทุกครั้ง ผู้ดูแลเปลี่ยนเป็น เผยแพร่ หลังตรวจว่าไม่มีข้อมูลส่วนบุคคล การกดส่งซ้ำใช้ UUID เดิมจึงไม่เพิ่มเหตุซ้ำ ไม่มีการสร้างตัวอย่างเหตุจริง

แชทสร้างแท็บ แชทจุดเสี่ยง เมื่อส่งข้อความแรก มีคอลัมน์ รหัสข้อความ เวลา ห้อง ชื่อเล่น ข้อความ สถานะ ผู้ดูแลเปลี่ยนสถานะ แสดง เป็น ซ่อน เพื่อไม่แสดงข้อความ ห้องรวมใช้ general ห้องจุดใช้รหัสจุดหรือพิกัด ข้อความแสดงย้อนหลัง 30 วัน สูงสุด 100 ข้อความต่อห้อง ข้อมูลเก่ายังอยู่ในชีท ไม่มีการลบอัตโนมัติ โหลดใหม่ทุก 15 วินาทีเฉพาะเมื่อ Popup เปิดและแท็บมองเห็น

กรองคำหยาบทั้งหน้าเว็บและเซิร์ฟเวอร์ รวมการคั่นเว้นวรรคและอักขระบางชนิด รายการคำเป็นตัวกรองพื้นฐาน อาจมีคำหลบเลี่ยงและคำที่ถูกปฏิเสธเกินจำเป็น แชทเป็นสาธารณะและชื่อเล่นไม่ยืนยันตัวตน ข้อความแสดงด้วย textContent เพื่อไม่รัน HTML ผู้ดูแลตรวจและซ่อนข้อความผ่านชีทได้

## การตรวจสอบก่อนเผยแพร่

ผ่าน syntax ของ script ทั้งหมด ทดสอบ mock Sheets: สถานะรอตรวจสอบ รหัสไม่ซ้ำ พิกัด/Level ผิดถูกปฏิเสธ สูตรข้อความถูก escape คำหยาบถูกปฏิเสธ ข้อความซ่อนและเกิน 30 วันไม่ส่งออก และ action เก่าคืน null เพื่อส่งต่อเส้นทางเดิม ยังต้องทดสอบ UI และ deployment จริงหลังเข้าสู่ระบบ Apps Script
